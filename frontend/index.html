Удалённые серверы

Генерация на другом компьютере по сети.

Подключить сервер

Как подключить
  1. Скачайте zip и распакуйте на компьютере с видеокартой. Эту панель туда копировать не нужно.
  2. Положите модель рядом со start.bat и назовите файл model.gguf.
  3. Запустите start.bat, выберите CPU или GPU. Окно не закрывайте — это и есть сервер модели.
  4. Если Windows спросит сеть — разрешите. Порт 8088 должен быть открыт (open-firewall.bat от администратора).
  5. В поле «Адрес» вставьте URL из окна, например http://192.168.1.50:8088. Это IP того компьютера, не этой панели.

Ключ API — это пароль к серверу модели. Обычно не нужен: оставьте пустым. Заполняйте только если при запуске задали --api-key: тогда сюда тот же пароль, иначе панель не подключится. Без ключа модель доступна всем в вашей сети.

Папка и задержки

Имя папки в Telegram и паузы перед прочтением и ответом. Пустое имя — стандартное TG-Assistant.

Как это работает

После запуска агента в Telegram появится папка. Туда перетаскивают личные чаты — бот отвечает только им. Переименование применится при следующем запуске агента.

Выгрузить чат

Выберите папку на аккаунте (например «Парсинг») и чат внутри неё. Выгружается весь текст, фото и аудио пропускаются.
