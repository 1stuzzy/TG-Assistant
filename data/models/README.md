# Модели GGUF (CPU)

Сюда кладите файлы `.gguf`. Панель подхватывает их автоматически.

Рекомендации без видеокарты (квантизация Q4_K_M):

1. **Qwen2.5 1.5B Instruct** — быстро, ~1 ГБ, для проверки пайплайна.
2. **Qwen2.5 3B Instruct** — лучший баланс для живого диалога на CPU.
3. **Qwen2.5 7B Instruct** — умнее, но медленнее; нужно ~8 ГБ RAM.

Скачать можно кнопкой в Настройках панели или вручную с Hugging Face
в репозитории `Qwen/Qwen2.5-*-Instruct-GGUF`.
