# Поведение живого диалога

Эта папка подхватывается при запуске агента. Личность задаётся **промтом** персонажа, здесь только как говорить.

| файл | как используется |
|---|---|
| `human_rules.json` | правила в системный промт (`system_suffix`, always, never) |
| `sepia.json` | слой структуры (StoryScope / Sepia): не объяснять тему, не штамп «реакция+вопрос» |
| `emotions.json` | тон ответа по реплике |
| `topics.json` | темы, которые можно затронуть |
| `dialogues.jsonl` | примеры стиля (few-shot). Если в уже идущем чате тишина, агент может написать сам |
| `dialogues.live.jsonl` | живые пары с кнопки «Выгрузить чат» (только админ). Сначала папка на аккаунте, затем чат: весь текст, без фото и аудио. Не коммитить |
| `slang.json` | дайвинчик / дв / винчик / лео = бот знакомств, не да Винчи |

Путь по умолчанию: `data/rules`. Переменная: `CONVERSATION_PACK_DIR`.
